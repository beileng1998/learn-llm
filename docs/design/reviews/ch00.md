# Chapter 00: novice-review log

Method: `docs/design/novice-review.md`. Each round uses fresh reviewers that never saw
earlier rounds.

## Round 1 (P1 + P2 in English, P3 in Chinese): 7 blockers

- Results appear *above* code with marimo's default settings, while the text says "below".
  Fixed with `[tool.marimo.display] cell_output = "below"` in `pyproject.toml`.
- Exercise 1 never said the input is called `celsius`; copying `x` from the example gives an
  unreadable `NameError`.
- Two levels of indentation (a loop inside a function) were never taught.
- Exercise 3 with an unfinished Exercise 2 said "not written yet", which wasn't true.
  The checker now reports "waiting for `total`" (`BLOCKED`).
- `if` and `>` were used before being explained.
- Raw English error messages were the only feedback for common mistakes. Common error
  types now get a translated hint.
- The `None` message blamed a missing `return` when the cause was the indentation of `return`.

## Round 2: 4 blockers, all subtler

- Learners using a Chinese input method type full-width `（）：，`, which gives an English-only
  `SyntaxError`. Found only by the Chinese-reader persona.
- Learners were asked to invent names without being told the rules (no spaces), or that
  they may pick any name.
- How to make and remove indentation in the editor was never said.
- A wrong answer to Exercise 2 (`running + n` not stored back) half-passed, because two
  check cases both expected 0. Changed one case.

## Round 3: 0 blockers (both languages)

Polish applied from the shaky spots: replace only the word `todo()` (deleting the whole line
also deleted its spaces); Shift + Enter moves to the next cell; quote marimo's real
"defined by another cell" message; say what `IndentationError` means and that the checks
come back after a typing slip is fixed; press Backspace once before writing `return`;
"only the first number comes back" means `return` is inside the loop.

Chapter 00 passes the gate.

## What this taught us about the method

- Self-review plus a working browser test found none of the round 1 blockers.
- Different personas find different things: P3 alone found the input-method problem.
- The checks' feedback is part of the lesson: half the blockers were about what the page
  says when the learner gets it wrong.
